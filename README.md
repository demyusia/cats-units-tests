# Модульное тестирование (Unit Tests): Программа исследования кошачьих

Проект посвящен комплексному модульному тестированию внутренней логики приложения для наблюдения за семейством кошачьих (`Feline`, `Cat`, `Lion`, `Alex`).

## Стек технологий
* **Язык разработки:** Java (11)
* **Тестовый фреймворк:** JUnit 4
* **Мокинг и изоляция:** Mockito
* **Контроль покрытия:** Плагин JaCoCo (Maven)
* **Сборщик проектов:** Maven

---

## Реализованный функционал и покрытие тестами

### 1. Тестирование основных классов (Покрытие 100%)
* **Класс Feline:** Проверены методы определения семейства (`getFamily`), подбора рациона питания (`eatMeat`) и подсчета потомства (`getKittens`).
* **Класс Cat:** Протестировано корректное взаимодействие с зависимостями при получении звуков кошки (`getSound`) и списка еды.
* **Класс Lion:** Полностью покрыты тестами методы определения наличия гривы в зависимости от пола животного, подсчет львят и рацион питания. 

### 2. Дополнительный функционал (Лев Алекс)
* **Класс Alex:** Создан и полностью покрыт тестами класс-наследник для льва Алекса из «Мадагаскара». 
  * Переопределен конструктор (по умолчанию фиксируется пол «Самец»).
  * Переопределен метод `getKittens()` с учетом отсутствия потомства.
  * Реализованы и протестированы уникальные методы `getFriends()` (список друзей: Марти, Глория, Мелман) и `getPlaceOfLiving()` (Нью-Йоркский зоопарк).

### 3. Особенности архитектуры и подходов
* **Инъекция зависимостей (Dependency Injection):** Проведен рефакторинг: класс `Lion` полностью изолирован от жесткой связи с `Feline` через конструктор.
* **Изоляция с Mockito:** Использованы моки и заглушки для исключения влияния связанных сущностей на результаты тестов.
* **Параметризация:** Созданы параметризованные тест-кейсы для валидации ветвления логики.
* **Контроль JaCoCo:** Достигнут показатель **100% Code Coverage** для всех целевых классов бизнес-логики.

## Запуск тестов и генерация отчета
Для запуска модульных тестов и сборки отчета о покрытии выполните:
```bash
mvn verify
```
*После успешного выполнения html-отчет JaCoCo будет сгенерирован по пути: `target/site/jacoco/index.html`.*
